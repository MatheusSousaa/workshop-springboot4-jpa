# Projeto Spring Boot & JPA

API RESTful desenvolvida durante os estudos de Java e Spring Boot, focada em um sistema de pedidos e e-commerce utilizando boas práticas de arquitetura em camadas e banco de dados relacional.

---

## Tecnologias
* Java
* Spring Boot (Web, Data JPA)
* Maven
* PostgreSQL / H2 Database
* Insomnia / Postman

---

## Funcionalidades
* Gerenciamento de Usuários (CRUD completo)
* Cadastro de Categorias e Produtos
* Registro de Pedidos e Pagamentos

---

## Como rodar
1. Clone o repositório.
2. Abra a pasta na sua IDE (IntelliJ).
3. Configure as credenciais do seu banco no `application.properties`.
4. Execute a classe principal `DemoApplication`.
